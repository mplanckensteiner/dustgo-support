# DustGo Privacy Policy

**Last updated: 28 October 2026**

DustGo is a macOS menu bar utility that pauses your keyboard (and, if you choose, your trackpad) for a short time so you can clean it, and can fill your displays with a solid color so you can spot dust and smudges.

## The short version

DustGo collects no data. Nothing you do in the app leaves your Mac.

## Data collection

DustGo has no accounts, no analytics, no advertising, no tracking, and no crash reporting of its own. It does not connect to the internet.

## Keyboard and trackpad input

While a cleaning session is active, DustGo discards keyboard events so they don't reach other apps. If you turn on "Pause trackpad too", it also discards clicks, scrolling, cursor movement, and trackpad gestures.

DustGo only looks at incoming events to recognize its unlock shortcut. It does not record, store, log, or transmit what you type or which keys you press, and it doesn't translate keys into characters. When the session ends, DustGo stops filtering input completely. It never watches your input outside a cleaning session.

## Accessibility permission

macOS requires the Accessibility permission before an app can pause keyboard input. DustGo uses this permission for that purpose only. You can turn it off at any time in System Settings → Privacy & Security → Accessibility. DustGo won't start a cleaning session without it.

## Settings stored on your Mac

DustGo saves your preferences locally using standard macOS user defaults:

- Cleaning duration
- Whether to show the countdown
- Whether to play sounds
- Whether to pause the trackpad too
- Whether to show the main window when DustGo opens
- Screen cleaning color

If you turn on "Launch at login", macOS manages that setting itself in System Settings → General → Login Items.

These settings never leave your Mac. Deleting DustGo removes them.

## Children

DustGo doesn't collect personal information from anyone, including children.
